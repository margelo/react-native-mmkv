# nitro-mmkv

Shared MMKV storage implementation, Nitro bindings, web and mock implementations, and React hooks. Import the adapter for your app so the host initializes storage before the first MMKV instance.

- [React Native](https://github.com/margelo/react-native-mmkv#readme)
- [React Nitro](https://github.com/margelo/react-native-mmkv/tree/main/packages/react-nitro-mmkv)
